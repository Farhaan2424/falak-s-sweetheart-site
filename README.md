# Falak's Sweetheart Site

Build a romantic, soft pink-and-white light theme birthday website called "Happy Birthday Falak" — a single-page app with smooth scroll/transition between sections, using React + Tailwind CSS. Make it feel warm, cozy, and handmade — like a digital love letter.

Design language:

Light pink, blush, cream, and white color palette with soft gradients (think #FFF0F5, #FFD1DC, #FFE4E1)

Background texture: a subtle crochet/knit pattern overlay (soft looping stitch pattern in a very light pink/white, low opacity, using CSS or SVG pattern) so it feels cozy and handmade, not flat

Rounded, soft UI elements (rounded-2xl or more), soft drop shadows, no harsh edges

Elegant script/cursive font for headings (like "Great Vibes" or "Dancing Script" from Google Fonts) paired with a clean readable font for body text

Floating decorative elements: small hearts, flowers, or ribbon doodles gently animating/floating in the background (CSS keyframe animation, slow and subtle, non-distracting)

Smooth fade-in and slide-up animations as sections come into view

Page structure:

Landing/Front Page

Big animated heading: "Happy Birthday Falak 💗" with a soft entrance animation (fade + scale)

A cute subheading/message (placeholder text, sweet tone)

A single button/prompt: "Do you want to see more? 🎀" that smoothly scrolls or transitions to the next section

Photo Gallery Section

Grid layout with at least 6 image placeholder cards (soft pink rounded frames, like polaroid/scrapbook style with a slight tilt/rotation on alternating images for a candid scrapbook feel)

Each placeholder should have a small caption area below it with placeholder text like "A memory to remember 💕"

Hover effect: slight zoom/lift on each photo card

Video Section

A clean video placeholder (rounded frame, pink border/frame styling) with a caption above it, e.g., "A little something for you 🎥"

Placeholder video area (use a styled empty video player box)

Letter Page

A section styled like an open envelope or unfolded letter (paper-like card with a slightly deckled/torn edge effect using CSS, or a folded paper illustration)

Placeholder heartfelt letter text with elegant typography, maybe a "signed with love" signature line at the end

A Little Extra (your creative touch)

Add a "Reasons I love you" flip-card or interactive counter section — small cards that flip or expand on click revealing a sweet reason (placeholder text), giving the site an interactive, playful surprise element

Optionally add a gentle background music toggle button (small floating music note icon, muted by default)

End the page with a soft closing animation — like floating hearts rising up, or a "Made with 💗" footer

Interactions:

Smooth scroll navigation between sections (small floating nav dots on the side, pink-themed)

All buttons should have soft hover/press animations

Mobile responsive — should look just as beautiful on phone

Keep all images and video as clearly marked placeholders (labeled "Add your photo here" / "Add your video here") so I can upload my own media later. Use tasteful, minimal, non-cheesy love-themed copy for placeholder text throughout.
